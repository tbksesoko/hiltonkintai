# 出勤時間申請サイト（Firebase ＋ GitHub Pages）

従業員は専用リンクから出勤・退勤・休憩を入力して申請し、管理者は確認・修正してExcelでダウンロードします。

| ファイル | 内容 |
|---|---|
| `index.html` | 従業員ページ（`index.html?id=…` の専用リンクで開く） |
| `admin.html` | 管理画面（ログインが必要） |
| `common.js` | Firebase接続・勤務表の表示と保存 |
| `calc.js` | 日付と勤務時間の計算 |
| `excel.js` | 提出用Excelの作成（見本の様式・A4縦1枚） |
| `xlsx-writer.js` | Excelファイルの書き出し（罫線・印刷設定つき） |
| `firebase-config.js` | Firebase の設定（**書き換えが必要**） |
| `firestore.rules` | データベースのアクセスルール（**管理者メールの書き換えが必要**） |
| `style.css` | デザイン |

## 勤務時間の計算（エクセル見本と同じ）

- 入は15分単位で**切り上げ**、退は15分単位で**切り捨て**、そこから休憩を引きます。
- 退が入より早い時刻のときは、翌日の退勤として計算します（夜勤）。
- 例：8:52〜17:40・休憩1:00 → 9:00〜17:30 − 1:00 ＝ **7:30**

## 初回の設定手順

### 1. Firebase プロジェクトを用意する
1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成します（既存のものを使ってもかまいません）。
2. **Firestore Database** を作成します（本番モード、ロケーションは `asia-northeast1`（東京）がおすすめ）。
3. **Authentication** →「始める」→ ログイン方法で **メール / パスワード** を有効にします。
4. Authentication →「ユーザー」→「ユーザーを追加」で、管理者のメールアドレスとパスワードを登録します。

### 2. 設定を書き換える
1. プロジェクトの設定 → マイアプリ →「ウェブアプリを追加」（`</>`）。表示された `firebaseConfig` を `firebase-config.js` に貼り付けます。
2. `firestore.rules` の `'admin@example.com'` を、手順1-4で登録した管理者のメールアドレスに書き換えます。複数人なら `['a@example.com', 'b@example.com']` のように並べます。
3. Firebase コンソール → Firestore →「ルール」タブに `firestore.rules` の中身を貼り付けて「公開」します。

### 3. GitHub Pages で公開する
1. GitHub で新しいリポジトリを作成します（例：`kintai`）。
2. このフォルダのファイルをすべてアップロードします（「Add file」→「Upload files」）。
3. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして保存します。
4. 数分後、`https://ユーザー名.github.io/kintai/admin.html` で管理画面が開きます。

### 4. Firebase に公開先を許可する
Authentication →「設定」→「承認済みドメイン」に `ユーザー名.github.io` を追加します（追加しないと管理者ログインができません）。

### 5. 使い始める
1. `admin.html` にログイン →「従業員と専用リンク」タブで社員番号と名前を登録します。
2. 発行されたリンクをコピーして、各従業員に送ります。
3. 月末に「勤務表」タブで内容を確認・修正し、「Excelでダウンロード」で全員分を出力します。
   - 1人1シート（シート名は名前）。見本のA〜F列の様式で、罫線つき・A4縦1枚に収まる印刷設定です。
   - 勤務時間の列は数式なので、Excel上で入・退・休憩を直しても自動で再計算されます。
   - 最後に「集計」シート（社員番号・名前・出勤日数・勤務時間合計）がつきます。

## 運用メモ

- **申請済み**の月は従業員側では入力できなくなります。本人が「申請を取り消す」か、管理者が「差し戻す」と再び入力できます。
- 管理者が修正した日は「修正」の印がつき、管理画面には申請時の時間も表示されます。
- 専用リンクを知っている人はその従業員のページに入力できます。リンクは本人にだけ送ってください。
- 従業員を削除しても、入力済みの勤務データは Firestore に残ります。
- データは `staff`（従業員）と `months`（従業員ID_年月ごとの勤務表）の2つのコレクションに保存されます。
